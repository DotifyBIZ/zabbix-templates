# Ownership

## Accountable for

The owning team keeps the two templates correct for Zabbix 6.0 and for the NAS
models Dotify monitors.

## Depends on, and depended on by

The catalog entry lists no dependencies and no consumers. The templates link to
standard Zabbix templates (ICMP Ping, Generic SNMP, and for QNAP also
EtherLike-MIB, Interfaces Simple SNMP and Network Generic Device SNMP), which
ship with Zabbix.

## Data

The repository holds template definitions only. It holds no monitoring data,
credentials or personal data.

## Recurring duties

None are defined in the repository.

## Lifecycle

The lifecycle is `production` in the catalog entry. How it is reviewed or
retired is not decided yet.
